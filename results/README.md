# Results

These folders contain selected benchmark data. Each dated folder has a README that explains its files and limits.

| Folder | Hardware | Contents |
|---|---|---|
| [`2026-11-03-24gb/`](2026-11-03-24gb/) | i5-13600KF, RX 9070 16 GB, 24 GB DDR4 | Throughput, synthetic checks, Hermes agent results, production fit, and sanitized resource samples |

The harness writes new runs to `results/raw/`. Git ignores that folder until results have been reviewed.

Published files contain benchmark measurements, pass or fail results, and tool sequences. They exclude prompts, generated responses, real account data, local paths, usernames, process IDs, credentials, and private configuration.
